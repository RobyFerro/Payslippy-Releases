Estrai dati da PDF.
Senza compromessi.

DocuMiner è la piattaforma desktop per trasformare documenti PDF in dati strutturati: disegna template visuali sui tuoi documenti, automatizza l'estrazione su cartelle intere e interroga i risultati come un database.

Tutto quello che serve per estrarre dati da PDF

Otto strumenti integrati che coprono l'intero ciclo: dalla definizione del template fino all'analisi finale.

Template visuali

Disegna bounding box direttamente sul PDF: nessun XML, nessuna configurazione manuale.

Tre metodi di estrazione

Testo nativo, OCR italiano/inglese e tabella AI: usa il metodo migliore per ogni campo.

Estrazione batch

Processa intere cartelle di PDF in un click e ottieni un CSV pronto da importare.

Programmazione a grafo

Trasforma i dati estratti con un editor visuale a nodi: niente codice, logica chiara.

Funzioni Python

Inserisci script Python per trasformazioni custom e integrazioni con altri sistemi.

Data Browser SQL

Interroga tutti i dati estratti con query SQL, come in un vero client database.

Moduli riutilizzabili

Organizza template in progetti e moduli condivisibili tra documenti simili.

Assistente AI

Genera script di estrazione e trasformazione partendo da una descrizione in linguaggio naturale.

Come funziona

Tre passi dal documento ai dati strutturati.

01

Definisci il template

Apri un PDF di esempio e disegna i bounding box sui campi che vuoi estrarre. Scegli per ognuno il metodo: testo, OCR o tabella AI.

02

Estrai in batch

Punta DocuMiner a una cartella di documenti simili: il template viene applicato a ogni file in automatico.

03

Esporta o interroga

Esporta in CSV per Excel/Power BI, oppure interroga i risultati direttamente con SQL nel data browser integrato.

Pensato per chi gestisce centinaia di documenti

Buste paga, fatture, polizze, certificati: ogni documento ha la sua struttura, ma con DocuMiner basta definirla una volta. Da lì in poi è solo un drag-and-drop di cartelle.

Tutto resta in locale: i tuoi PDF non lasciano mai la tua macchina, salvo che tu non scelga esplicitamente di usare un servizio AI per l'estrazione tabellare.

Domande frequenti

Le risposte alle domande che riceviamo più spesso. Non trovi quello che cerchi? Apri una issue.

DocuMiner è gratuito?
Sì, la versione base è gratuita e permette di elaborare fino a 10 file per batch con fino a 5 nodi nei grafi di trasformazione. La versione Pro rimuove ogni limite.
I miei PDF vengono inviati a server esterni?
No, di default tutta l'estrazione avviene in locale sul tuo computer. Solo se attivi esplicitamente l'estrazione tabellare via AI o l'assistente AI viene inviata una porzione minima di dati al provider selezionato (schema e campioni limitati, mai i PDF originali).
L'OCR supporta l'italiano?
Sì, l'OCR integrato è quello nativo di Windows e supporta sia italiano sia inglese, senza necessità di pacchetti aggiuntivi.
Come funziona l'aggiornamento automatico?
DocuMiner controlla periodicamente questo stesso repository GitHub e propone l'aggiornamento quando è disponibile una nuova versione. Puoi accettare o rimandare: nessun download automatico in background.
Posso usarlo offline?
Sì, tutte le funzioni base (template, estrazione testo, OCR, batch, esportazione CSV, SQL) funzionano completamente offline. Solo le funzioni AI richiedono connessione.
Funziona su Mac o Linux?
Al momento no: DocuMiner è una applicazione Windows nativa (WPF) e dipende da componenti specifici della piattaforma (OCR di Windows, rendering PDF). Una versione cross-platform non è in roadmap.
